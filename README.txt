# Aurora FC — site

Arquivos:
- `index.html` — estrutura e conteúdo do site
- `style.css` — visual azul e branco, responsivo para celular
- `script.js` — navegação, elenco e botões

## Colocar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `script.js` e a pasta `assets`.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch principal (geralmente `main`) e a pasta `/ (root)`.
6. Salve e aguarde o GitHub Pages publicar.

## Onde colocar os escudos
Quando você mandar o escudo do Aurora e o do Guarulhos FC, eles podem substituir os placeholders `A` e `G` do site.

Os escudos reais estão em `assets/aurora.jpg` e `assets/guarulhos.jpg`.
